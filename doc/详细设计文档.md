# HTML 简历编辑器 - 系统详细设计文档

## 1. 系统概述

### 1.1 项目背景
基于 AI+HTML 的动态低代码简历编辑器，支持可视化编辑简历内容、实时预览、多套样式切换、模块拖拽排序等功能。

### 1.2 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue 3 + Vite | 3.4+ |
| 前端 UI | Element Plus | 2.5+ |
| 前端拖拽 | vuedraggable / sortablejs | 4.x |
| 后端 | Java | 21 |
| 后端框架 | Spring Boot | 3.4 |
| ORM | MyBatis-Plus | 3.5+ |
| 数据库 | MySQL | 8.0 |
| 构建工具 | Maven | 3.9+ |

## 4. API 接口设计

### 4.1 接口规范

- 统一前缀：`/api/v1`
- 请求格式：`application/json`
- 响应格式：`{ code: 200, message: "success", data: {} }`
- 认证方式：基于 device_id 的简单认证（Header: X-Device-Id）

### 4.2 接口列表

#### 4.2.1 用户相关

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 初始化用户 | POST | `/api/v1/users/init` | 根据 device_id 初始化用户 |

#### 4.2.2 简历管理

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 创建简历 | POST | `/api/v1/resumes` | 创建新简历 |
| 查询简历列表 | GET | `/api/v1/resumes` | 获取用户所有简历 |
| 查询简历详情 | GET | `/api/v1/resumes/{id}` | 获取简历详情（含模块数据） |
| 更新简历标题 | PUT | `/api/v1/resumes/{id}` | 更新简历标题 |
| 删除简历 | DELETE | `/api/v1/resumes/{id}` | 删除简历 |

#### 4.2.3 模块管理

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取模块配置 | GET | `/api/v1/module-config/{moduleType}` | 获取指定模块类型的字段配置 |
| 添加模块 | POST | `/api/v1/resumes/{resumeId}/modules` | 添加简历模块 |
| 更新模块内容 | PUT | `/api/v1/modules/{id}` | 更新模块内容 |
| 删除模块 | DELETE | `/api/v1/modules/{id}` | 删除模块 |
| 调整模块排序 | PUT | `/api/v1/resumes/{resumeId}/modules/sort` | 批量调整模块顺序 |

#### 4.2.4 样式管理

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 查询样式列表 | GET | `/api/v1/styles` | 获取所有可用样式 |
| 查询样式详情 | GET | `/api/v1/styles/{id}` | 获取样式详细内容 |
| 切换简历样式 | PUT | `/api/v1/resumes/{resumeId}/style/{styleId}` | 切换简历样式 |
| 保存自定义样式 | POST | `/api/v1/resumes/{resumeId}/style-config` | 保存自定义样式覆盖 |

#### 4.2.5 导入导出

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 导出简历 | GET | `/api/v1/resumes/{id}/export/html` | 导出完整 HTML 文件 |
| 导出 JSON | GET | `/api/v1/resumes/{id}/export/json` | 导出 JSON 数据 |
| 导入简历 | POST | `/api/v1/resumes/import` | 导入 JSON 数据创建简历 |

### 5.2 核心组件说明

#### 5.2.1 Editor.vue（编辑器主页面）
- 布局：三栏布局（左/中/右）+ 顶部工具栏
- 状态：管理当前编辑的简历数据、模块列表、排序状态
- 功能：加载简历数据、自动保存、模块拖拽排序

#### 5.2.2 LeftPanel.vue（左侧模块面板）
- 展示所有可用模块列表
- 支持模块拖拽排序（使用 vuedraggable）
- 支持添加/删除模块
- 点击模块聚焦到对应编辑区域

#### 5.2.3 DynamicForm.vue（动态表单）
- 根据 `module_type_config` 配置动态渲染表单
- 支持字段类型：text/textarea/date/select/switch/image
- 支持表单校验
- 支持字段显示/隐藏控制

#### 5.2.4 HtmlPreview.vue（HTML 预览）
- 根据模块数据和样式配置生成 HTML
- 使用 iframe 隔离样式
- 支持实时更新

#### 5.2.5 CssEditor.vue（CSS 编辑器）
- 可视化 CSS 编辑（颜色选择器、字体选择器等）
- 支持切换到代码模式直接编辑 CSS
- 支持保存为自定义样式

## 6. 核心业务流程

### 6.1 初始化流程

```
用户打开页面
    │
    ▼
生成/读取 device_id (localStorage)
    │
    ▼
POST /api/v1/users/init
    │
    ▼
查询该用户简历列表
    │
    ▼
无简历 → 自动创建默认简历
    │
    ▼
加载简历详情 + 模块数据 + 样式配置
    │
    ▼
渲染编辑器界面
```

### 6.2 模块拖拽排序流程

```
用户在左侧面板拖拽模块
    │
    ▼
vuedraggable 触发 @end 事件
    │
    ▼
获取新的模块顺序数组
    │
    ▼
PUT /api/v1/resumes/{id}/modules/sort
    { modules: [{id, sortOrder}, ...] }
    │
    ▼
后端批量更新 sort_order 字段
    │
    ▼
重新按 sort_order 排序获取模块
    │
    ▼
更新预览区域
```

### 6.3 HTML 生成流程

```
前端获取简历数据（basic_info + modules）
    │
    ▼
根据 module_type_config 获取字段布局配置
    │
    ▼
遍历模块，根据 layout_type + html_tag 生成 HTML 片段
    │
    ▼
拼接完整 HTML 结构
    │
    ▼
注入 css_style.css_content 样式
    │
    ▼
渲染到 iframe 中
```

### 6.4 自动保存流程

```
用户在编辑面板修改字段
    │
    ▼
触发 debounce 计时器（1s）
    │
    ▼
组装模块内容 JSON
    │
    ▼
PUT /api/v1/modules/{id}
    { content: {...} }
    │
    ▼
更新成功 → 显示保存成功提示
    │
    ▼
更新失败 → 显示错误提示
```

## 11. 关键实现细节

### 11.1 HTML 生成逻辑

```javascript
// htmlGenerator.js - 核心函数
export function generateHtml(resumeData, cssStyle) {
  const { modules, styleConfig } = resumeData;
  
  // 按 sortOrder 排序
  const sortedModules = modules.sort((a, b) => a.sortOrder - b.sortOrder);
  
  // 生成各模块 HTML
  let sectionsHtml = '';
  for (const module of sortedModules) {
    sectionsHtml += generateModuleHtml(module);
  }
  
  // 组装完整 HTML
  return `
    <!DOCTYPE html>
    <html lang="zh-CN">
    <head>
      <meta charset="UTF-8" />
      <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
      <title>${resumeData.title}</title>
      <style>${cssStyle.cssContent}</style>
    </head>
    <body>
      <div class="resume">
        ${sectionsHtml}
      </div>
    </body>
    </html>
  `;
}
```

### 11.2 动态表单渲染逻辑

```vue
<!-- DynamicForm.vue -->
<template>
  <el-form :model="formData">
    <el-form-item
      v-for="field in fieldConfigs"
      :key="field.fieldKey"
      :label="field.fieldName"
      v-if="field.isVisible"
    >
      <!-- 根据 field_type 渲染不同组件 -->
      <el-input v-if="field.fieldType === 'text'" v-model="formData[field.fieldKey]" :placeholder="field.placeholder" />
      <el-input v-else-if="field.fieldType === 'textarea'" type="textarea" v-model="formData[field.fieldKey]" />
      <el-date-picker v-else-if="field.fieldType === 'date'" v-model="formData[field.fieldKey]" />
      <el-select v-else-if="field.fieldType === 'select'" v-model="formData[field.fieldKey]">
        <el-option v-for="opt in field.options" :key="opt.value" :label="opt.label" :value="opt.value" />
      </el-select>
      <el-switch v-else-if="field.fieldType === 'switch'" v-model="formData[field.fieldKey]" />
      <el-upload v-else-if="field.fieldType === 'image'" />
    </el-form-item>
  </el-form>
</template>
```

### 11.3 拖拽排序逻辑

```vue
<!-- LeftPanel.vue -->
<template>
  <draggable
    v-model="modules"
    item-key="id"
    handle=".drag-handle"
    @end="onDragEnd"
  >
    <template #item="{ element }">
      <div class="module-card">
        <span class="drag-handle">⋮⋮</span>
        <span>{{ getModuleLabel(element.moduleType) }}</span>
        <el-icon @click="removeModule(element.id)" class="delete-icon"><Delete /></el-icon>
      </div>
    </template>
  </draggable>
</template>

<script setup>
import { updateModuleSort } from '@/api/module';

function onDragEnd() {
  const sortedModules = modules.value.map((m, index) => ({
    id: m.id,
    sortOrder: index + 1
  }));
  updateModuleSort(resumeId.value, sortedModules);
}
</script>
```
